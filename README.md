# Windows 11 IT Support Home Lab

## Overview

This project was created to develop practical IT support and troubleshooting skills using a Windows 11 virtual machine hosted in VirtualBox. The lab was built alongside my CompTIA A+ studies to gain hands-on experience with Windows administration, user management, software installation, networking fundamentals, and troubleshooting processes commonly used in IT support environments.



## Objectives

The objectives of this project were to:

* Install and configure a Windows 11 virtual machine.
* Develop familiarity with Windows administration tools.
* Practise user account management and permissions.
* Gain experience installing and managing software.
* Learn and apply networking diagnostic commands.
* Develop structured troubleshooting and documentation skills.



## Technologies Used

* VirtualBox
* Windows 11
* Command Prompt
* Windows Administrative Tools
* GitHub



## Project Activities

### Virtual Machine Setup

* Installed Oracle VirtualBox.
* Downloaded and configured a Windows 11 ISO.
* Created and configured a Windows 11 virtual machine.
* Completed Windows installation and initial setup.

### User Account Management

* Created Administrator and Standard User accounts.
* Tested user permissions and account restrictions.
* Practised managing local user accounts.

### Software Installation

* Installed common applications including:

  * Google Chrome
  * Brave
  
### Windows Administration

Explored and used:

* Task Manager
* Device Manager
* Disk Management
* Event Viewer
* System Information

### Networking Diagnostics

Practised the following commands:

- cmd
- ipconfig
- ipconfig /all
- ping google.com
- tracert google.com
- nslookup google.com
- hostname
- systeminfo


## Skills Demonstrated

* Windows 11 installation and configuration
* User account administration
* Software deployment and management
* Basic networking and diagnostics
* Troubleshooting and root cause analysis
* Documentation and record keeping
* Independent learning and problem solving


## Key Learning Outcomes

Through this project I developed practical experience working with Windows operating systems, troubleshooting common technical issues, and documenting resolutions using a structured support process. The project strengthened my understanding of core IT support concepts and provided hands-on experience that complements my CompTIA A+ studies.
